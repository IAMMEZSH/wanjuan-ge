# 万卷阁 · 书目与公版来源

版本 1.1.2 · 更新日期 2026-11-14

本清单说明万卷阁内置 171 部典籍的底本、仓库编号、许可与已知限制。程序只收录**已进入公有领域的原文**或**本项目原创的导读/译文**，不包含现代出版社的排印、标点、校注、白话译本或版权译本；现代版权作品（侦探小说、漫画等）一律只提供原创导读，不收录正文。

> 书目会随版本变化。运行 `npm run index` 后，`library/catalog.json` 中的 `source` 字段是最准确的机器可读来源；本文件为人工整理说明。

## 三、已知限制与编辑原则

1. **不伪造全文**：连山易、归藏易等佚书只存辑佚与转引，不补写“原文”；烧饼歌、乾坤万年歌按民间通行本收录全文，托名与真伪争议在解说与“本版说明”中交代；《格庵遗录》六十篇按通行本系统互校整理并完整收录，真伪与版本争议在导读与“本版说明”中交代。
2. **不做现代校勘**：Kanripo 底本为白文或旧注，未经本项目重新校勘；异体字、繁简与分段保留底本面貌。
3. **不内置版权译本**：需要现代注释或权威今译时，请自行购买或导入合法文本；程序的“在线翻译”只是机器译文，不能替代权威译本。
4. **圣经范围**：和合本仅新教正典 66 卷，次经/旁经不在其中；《死海古卷》是独立的第二圣殿时期文献译述，不属于这 66 卷正典。
5. **埃及死者之书**：选译十二篇，不是全本；布奇译本带有 19 世纪埃及学背景，术语与转写不代表当代学界共识。
6. **死海古卷**：80 章为中文译述与导读，按通行校勘本结构整理，残缺处以省略号标注；不是学术校勘本，也不替代专业译本。
7. **柯尔布林圣经**：只提供原创导读，不复制受版权保护的正文；如读者需要原文，请向权利人获取。
8. **数字化差异**：同一典籍在不同整理本中可能存在字句差异；本程序以所列底本为准，不保证与纸本或其他电子本完全一致。
9. **新增教材与习题均为原创**：语文、数学、英语、计算机、科学、驾考、文化与诗词曲书籍的正文、题目与解析均为万卷阁原创；驾考法条依据 2021 年修正《道路交通安全法》等现行文本，法规修订后以最新公布文本为准；诗词曲原文属公有领域。
10. **现代版权作品只做原创导读**：十宗罪、心理罪、埃勒里·奎因、东野圭吾、DC 漫画、漫威漫画等均为受版权保护的现代作品，本程序只收录原创导读，不收录正文、画面、台词与情节原文转述；需要原著请购买正版纸本或订阅官方数字平台。
