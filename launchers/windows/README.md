# 万卷阁 · Windows 启动器

本目录包含 Windows 10 / 11 的两个启动方式，二者都要求本机已安装 **Node.js 18 或更新版本**（程序零第三方依赖，不需要 `npm install`）。

| 文件 | 用途 | 是否保留控制台 |
| --- | --- | --- |
| `万卷阁.bat` | 推荐。检查 Node → 启动服务 → 1 秒后打开浏览器 | 是，可看日志与实际端口 |
| `万卷阁-无窗口.vbs` | 可选。后台静默启动，自动打开浏览器 | 否，出错不易排查 |

## 使用步骤

1. 安装 Node.js：打开 <https://nodejs.org/> 下载 LTS 安装包，安装时勾选 “Add to PATH”。
2. 解压整个发行包到普通目录，例如 `D:\万卷阁`。不要放在 `C:\Program Files` 等受保护位置。
3. 双击 `launchers\windows\万卷阁.bat`。
4. 浏览器会自动打开 <http://127.0.0.1:7410>。若没有自动打开，手动访问该地址。

启动后会弹出一个标题为「万卷阁 服务端」的命令行窗口：

- **关闭该窗口即停止服务**。
- 日志里会打印实际监听地址，例如 `万卷阁 v1.1.3 已启动：http://127.0.0.1:7410`。
- 按 `Ctrl+C` 也可以停止。

## 端口被占用

默认端口是 `7410`。若被其他程序占用，`server.js` 会自动尝试 `7411`–`7430`，控制台会打印实际端口。启动器检测到 7410 被占用时会给出提示，请以控制台输出的地址为准。

也可以指定端口：

```bat
set WANJUAN_PORT=8080
node server.js
```

查看谁占用了端口：

```bat
netstat -ano | findstr :7410
```

## 无窗口启动（可选）

双击 `万卷阁-无窗口.vbs` 后，服务在后台运行并自动打开浏览器。停止方法：

1. 打开任务管理器；
2. 切到「详细信息」；
3. 找到 `node.exe`，结束任务。

> 若需要查看日志或端口，请使用 `万卷阁.bat`，不要用 VBS。

## 常见问题

- **窗口一闪而过**：说明 Node 未安装或不在 PATH。用命令行运行 `node -v` 验证；也可在 `cmd` 中进入本目录执行 `node ..\..\server.js` 查看报错。
- **SmartScreen 提示**：这是未签名的批处理脚本。确认文件来自本项目发行包后，点「更多信息 → 仍要运行」。
- **端口 7410–7430 全被占用**：先关闭多余的 Node 进程，或设置 `WANJUAN_PORT` 指定其他端口。
- **杀毒软件拦截**：程序只监听 `127.0.0.1`，不联网、不写系统目录。可将项目目录加入信任。
- **中文乱码**：启动器已执行 `chcp 65001`；若仍乱码，请使用 Windows Terminal 或 PowerShell 运行。

## 数据位置

书签、笔记、进度、设置和 API Key 都保存在项目目录的 `data\` 下：

- `data\user.json`：设置与阅读数据（**含 API Key，备份时注意保密**）；
- `data\translations\`：译文缓存；
- `data\search-index.json`：全文索引，可删除后重建。

备份时复制整个项目目录，或至少复制 `data\` 与 `library\books\`。
